Desktop / Mobile navigation

DESKTOP 1440 · TOP NAV 64px 좌: 가로형 로고(240px / max-h 56) · 중앙: 8개 메뉴, 활성은 2px teal 언더라인 · 우: ⌘K 검색, 알림, Discord 프로필, 계정 메뉴. 페이지 내부는 필요한 경우만 좌측 Sub-sidebar(Build Lab, Database, Admin).
TABLET 1024 메뉴 8개 → 아이콘+짧은 라벨, 검색은 아이콘으로 축소. Dashboard는 12 → 8 column.
MOBILE 390–430 · BOTTOM NAV 5 + DRAWER 하단: HOME · SEASON · OPS · LAB · MORE. MORE 드로어에 MEMBERS · MAP · COMMUNITY · DATABASE · ADMIN. 상단은 Hex 엠블럼(32px) + 시즌 상태 칩 + 검색. 구조 재배치: Build Lab은 슬롯 → 풀스크린 시트, Stats는 하단 고정 요약 바. Map은 툴바를 상단 1줄로 접고 지도 70vh. Operations는 RSVP 버튼이 하단 고정. Profile은 탭을 가로 스크롤.
