# 게임 정보와 DPS 기록 형식

2026-10-09 구현 기준이다. `/db`에서 승인된 실측 DPS 자료를 검색·열람하고, 승인된 실제 멤버는 본인의 측정 조건과 결과·원본 증거를 등록해 게시 검토를 요청할 수 있다. **DPS 가상 예시 한 건**은 실제 자료와 구분해 선택적으로 표시한다. 효과 검증과 측정 가이드에는 등록 자료가 없으며, 없는 자료의 상세 주소를 만들어 표시하지 않는다.

## 현재 제공 범위

- `/db`: 분류별 실제 승인 자료와 예시 여부를 확인하는 목록.
- `/db/dps/sample-sustained-dps`: 조건, 반복 결과, 측정 절차와 증거 안내를 보여주는 예시 상세.
- `/db/new`, `/db/mine`: 실제 멤버의 작성과 본인 기록 목록. 임시 저장과 제출을 구분하며 수정은 새 버전으로 기록한다.
- `/db/dps/[id]?version=N`: 고정 버전의 측정 조건·반복 결과·원본 이미지·유튜브 증거와 검토 상태. 작성자는 본인의 버전, 운영진은 제출된 버전, 방문자는 공개 조건을 충족한 승인 버전만 열람한다.
- `/admin/database`: `OFFICER`·`ADMIN`은 제출 자료와 근거를 조회하고, 공개 승인 자료에 재현 확인을 남길 수 있다. 게시 승인·보완 요청·반려·게시 중단 결정은 `ADMIN`만 처리한다. 미제출 초안은 다른 작성자의 자료 검토 대상이 아니다.
- 통합검색의 `research` 분류: 방문자는 게시 승인 자료, 작성자는 본인의 최신 버전도 찾는다. 운영진 검토 권한만으로 다른 작성자의 미공개 버전이 검색되지는 않는다. 제목·요약·장비 구성·패치·시나리오·측정 조건·절차·증거 설명을 검색하며 이미지 바이트는 조회하지 않는다. 예시는 ‘화면 예시 · 실측 아님 · 미검증’, 실제 자료는 게시 승인과 재현 검토 상태를 구분한다.

예시의 작성자, 장비, 대상, 거리, 버프 조건, DPS와 반복값은 화면을 확인하기 위한 가상 자료다. 증거 영상이나 스크린샷, 실제 검토자는 없으며 `exampleOnly: true`, `verification: UNVERIFIED`로 유지한다. 반복 표가 있다고 검증 완료로 판단하거나 실제 무기 성능·추천 순위로 해석하지 않는다.

## 표시 설정

`.env.example`의 `GAME_INFO_EXAMPLES=single`은 가상 예시 한 건을 표시한다. `GAME_INFO_EXAMPLES=off`는 목록·상세 조회·관리 미리보기·검색에서 게임 정보 예시를 숨긴다. 게임 정보 페이지 자체와 안내는 유지한다. 설정을 바꾼 환경에서는 앱을 다시 시작한다.

예시는 `apps/web/src/lib/game-info-examples.ts`에 분리하고 서버의 `getGameInfoRecords()`를 목록과 검색이 함께 사용한다. 예시는 운영 DB에 저장하지 않는다. 실제 자료는 별도 DPS 기록·버전·게시 포인터·재현 검토 테이블에 보존하며 `GAME_INFO_EXAMPLES=off`에서도 계속 표시한다. 이 설정은 실제 자료와 기존 로컬 sample seed의 보관·정리와 독립적이다.

검색의 예시와 실제 자료는 하나의 게임 정보 분류로 합친다. 예시는 첫 페이지에 한 번만 표시하며 전체 검색 미리보기 5개, 분류별 페이지 20개 안에서 실제 자료의 조회 위치를 함께 조정한다.

## 실제 기록에 필요한 항목

실제 제출 자료는 기존 [Benchmark Profile 계약](../packages/build-engine/src/model/field-contracts.ts)과 [Build Data Specification](build-data-spec-v0.1.md)을 기준으로 다음을 기록한다.

- 게임 패치·시나리오·트랜스 현상·플랫폼과 빌드의 정확한 고정 버전.
- 측정 대상·난이도·거리·피격 부위·치명타/약점 조건.
- 시작·종료 기준, 측정 시간, 재장전·준비 시간 포함 여부, 시작 자원.
- 음식·음료·감염물·크래들·팀 버프와 시작 상태.
- 회차별 관찰값·오차, 원본 영상/스크린샷 등 증거와 검토자.

조건이 다른 결과를 같은 기준으로 비교하거나 훈련 대상의 결과를 보스 피해로 일반화하지 않는다. 예시 숫자는 실제 관찰값과 섞지 않는다. 게시 승인은 자료의 공개 여부이고 재현 검토 완료와 구분된다. 높은 재현 라벨은 최소 3회 반복, 원본 영상 또는 연결된 측정 이미지, 작성자를 제외한 서로 다른 현재 `OFFICER`·`ADMIN` 두 명의 재현 확인을 충족해야 한다. 검토자의 승인 역할·Discord 연결이 없어지면 그 확인은 이력으로 남아도 높은 라벨에 포함하지 않는다.

## 공개 범위와 원본 증거

작성 중인 자료와 등록 직후 이미지는 본인에게만 보인다. 운영진은 명시적으로 제출된 버전의 증거를 검토할 수 있다. 공개 이미지 URL도 해당 연구 버전의 권한을 매번 확인하고 `private, no-store`로 응답하며, 이미지 ID를 알거나 운영진이라는 이유만으로 다른 사람의 미제출 증거를 열 수 없다.

승인된 이전 버전은 활성 승인 게시가 유지되는 동안 고정 링크와 증거를 보존한다. 새 초안·검토 대기 버전은 공개하지 않으며 기존 승인 버전의 내용을 바꾸지 않는다. 숨김·보관·게시 중단, 작성자의 승인 역할·Discord 연결 해제 시 공개 접근과 검색을 차단한다. 빌드를 연결한 연구 자료는 해당 고정 빌드 버전과 현재 빌드 게시 모두 `PUBLIC` 승인 조건을 충족해야 방문자에게 공개한다. 하이브 한정·미승인 빌드의 내용이 연구 자료를 통해 공개되지 않도록 이미지·상세·검색에서 같은 조건을 사용한다.

## 후속 개발

실측 자료의 등록·새 버전·검토·게시·원본 증거 열람과 이력은 제공한다. 현재 페이지는 계산기나 DPS 시뮬레이터가 아니며 예시 수치를 계산 엔진의 결과로 표시하지 않는다. 기존 장비 원본 카탈로그, `BuildVersion` snapshot, 출처 검증 모델과 빌드 엔진을 변경하지 않는다.

실제 DPS 계산은 현재 패치의 기초 스탯, 효과 적용 순서·중첩·반올림, 대상 조건을 검증한 뒤 별도로 구현한다. 측정 기록을 공개하는 기능과 장비에서 DPS를 계산하는 기능은 각각 검증해야 한다.
