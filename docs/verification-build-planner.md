## 브라우저 확인

실제 승인 계정으로 `/lab/new`를 열고 P90·울프 6부위·닥터 테디, 쇄빙〈어빌리티〉Lv.13, 확인된 총구/사이트/전술/총알을 선택했다. 추천 4점·보스·약점 태그, 정확한 어빌리티/활성 등급 라벨과 세트 6부위 요약을 확인했다. 모듈에 13.5를 입력하면 값은 남고 aria-invalid와 안내가 표시되며 저장이 비활성화됐다. 닥터 테디→나비의 꿈 교체 시 두 등급이 비워지고 나비의 세 특성을 선택할 수 있었다. Escape로 선택창을 닫으면 원래 슬롯에 포커스가 돌아왔다.

1440px PC에서 문서 폭 1425px, 390px 모바일에서 375px으로 가로 넘침이 없었고 로드가 완료된 깨진 이미지가 없었다. 모바일 선택창·링의 그리드 전환도 확인하고 검수 화면 크기 설정을 되돌렸다. 브라우저 저장 버튼은 정상 입력에서 활성화됐다. 새 폼 검수는 영구 테스트 빌드를 생성하지 않았다.

브라우저에서 영구 테스트 빌드를 생성하지 않았다. 저장·버전·공개 범위 검증은 실제 PostgreSQL rollback 테스트와 Server Action 경계 테스트로 수행했다. 테스트 후 실제 `builds`·`build_versions`는 각각 0건이었다. 기존 운영 데이터·권한·Discord credential은 변경하지 않았다.

검수 이미지는 Git에 제외된 `artifacts/build-planner-v2.png`에 저장한다. 개발 서버는 `http://127.0.0.1:3000`에서 실행한다. 실제 사용하는 `.env`·token·UID를 문서나 검수 출력에 넣지 않는다. 30개 원본 PNG 합계는 476,876바이트이며 화면에서는 필요한 이미지를 지연 로딩한다. NPK/게임 데이터 추출은 개발 중 오프라인으로만 수행하고 페이지 요청·선택마다 실행하지 않는다.
