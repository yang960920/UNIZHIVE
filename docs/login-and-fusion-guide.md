# 로그인과 감염물 융합 준비 안내

2026-10-07 적용.

## 로그인

- 로그인과 Discord 가입 신청을 구분한다. 승인 회원은 기존 프로필과 승인을 유지하고 요청한 내부 화면으로 돌아간다.
- 유효한 실제 회원 세션은 로그인 화면을 생략한다. 신규·승인 대기·보류 회원은 기존 가입 상태를 유지한다.
- 회원 프로필 편집은 `/onboarding?edit=1`에서 제공한다.
- 복귀 주소의 외부 이동·인증 경로 반복을 차단하며, 헤더의 로그인 링크는 현재 경로와 검색·버전 쿼리를 보존한다.
- 로그인 완료 응답은 안전한 상대 Location을 사용한다. 내부 요청 주소가 localhost여도 브라우저가 사용하는 127.0.0.1 주소를 바꾸지 않는다.
- 검증된 승인 회원의 인증 완료 이력 쿠키는 동의 화면 선택에만 사용한다. 인증·권한 증거가 아니며 Guild 확인, 현재 역할, 세션 유지 정책을 대체하지 않는다.
- 기존 동의 이력이 있으면 동의 생략을 시도하고, 오류 후에는 사용자가 일반 인증으로 재시도한다. 실제 Discord의 동의 생략은 새 OAuth 왕복 검증이 남아 있다.

## 융합 준비 안내

- Build Lab 편집기의 감염물 상세와 저장된 장착 구성표에서 ‘융합 재료 보기’를 펼친다.
- 현재 장비 목록의 전투 감염물 23종과 특성 171개를 대상으로 선택한 목표 특성의 재료를 안내한다. 영지·창조 감염물 선택 슬롯 확장은 포함하지 않는다.
- 실제 재료 64개(동물 12개 ID·가구 52개)를 원본 item_data와 아이콘으로 연결한다. 재료의 변형·ID를 보존하며 동물 12종이라는 뜻은 아니다.
- 일반 특성은 해당 특성을 가진 감염물, 이로치 특성은 해당 종류의 감염물을 준비하도록 안내한다. 개별 획득 위치가 미확인인 경우 명시한다.
- 원본 특성 추가 규칙과 외형 변환 레시피를 구분한다. 외형 레시피 대상만으로 늑대·곰의 특성 추가를 제한하지 않는다.
- 메인 2개·보조 최대 3칸, 보조 소모, 서로 다른 메인의 목표 종류 보강, 경쟁 특성, 같은 아이콘·이로치 중복 제한을 안내한다.
- 활성·어빌 등급은 별도 참고이며 확률 계산이나 5/5 결과 보장은 제공하지 않는다.
- 준비 목록을 복사할 수 있다. 안내 열기·닫기·복사는 장비 구성이나 저장 버전을 변경하지 않는다.
- 닫힌 안내는 재료 이미지를 렌더링하지 않는다. 열린 저장 카드만 전체 폭으로 확장하고 특성 카드는 넓은 화면 3열·중간 2열·모바일 1열이다.

아이콘 증거: `packages/build-engine/data/fusion-guide-material-provenance.json`.
재생성 도구: `packages/build-engine/scripts/build-fusion-guide-data.mjs`.
실행 중에는 게임 파일 추출·DB 조회·외부 사이트 수집을 수행하지 않는다.

## 검증

권한·안전한 복귀·호스트 유지·가입/프로필 편집 경계, 재료 ID·아이콘 해시·선택 특성 충돌, 안내/복사 무변경을 자동 검사한다. 실제 Chrome에서 승인 계정의 버전 쿼리 유지, 가입 화면 생략, 프로필 수정 접근, 저장/편집 가이드와 준비 목록 복사를 확인한다. 모바일 390px에서 가로 넘침과 완료된 이미지 누락을 확인한다.

검수 이미지는 `artifacts/login-fusion-guide/`에 보관한다. 기존 사용자 탭은 조작하지 않고 별도 검수 탭을 사용한다. 서버를 재시작하거나 운영 데이터를 직접 수정하지 않는다.
