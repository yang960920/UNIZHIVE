# 계정 설정과 통합 검색

2026-10-08 구현 기준이다. 헤더 검색은 `/api/search`와 `/search`를 사용한다. 메뉴 이동 외에 실제 게시물과 사이트에 등록된 게임 자료를 찾는다.

## 통합 검색

- 빌드 제목·설명·최신 버전의 추천 태그/콘텐츠/메모, 커뮤니티 제목·본문, 공지, 파티 제목·설명·집합 장소, 승인된 시즌과 서버를 검색한다.
- 파밍 대상, 시나리오별 획득 조건, 장소별 드랍 안내, 한국어 장비 카탈로그와 홈에 표시하는 최신 한국어 공식 뉴스도 포함한다.
- 게임 정보의 실제 DPS 자료와 선택적으로 표시하는 가상 예시를 `research` 분류 하나로 검색한다. 방문자와 다른 멤버에게는 공개 승인 버전, 작성자에게는 본인의 최신 버전을 검색하며 운영진의 검토 권한으로 타인의 미공개 자료가 일반 검색에 추가되지 않는다. 예시는 첫 페이지에만 한 번 표시하고 `GAME_INFO_EXAMPLES=off`는 실제 자료의 검색을 끄지 않는다. 게시 승인과 재현 검토 상태를 구분해 안내하며 [게임 정보 범위](game-info.md)를 참고한다.
- 공백과 붙여쓰기를 정규화하고 SQL 특수 문자는 문자 그대로 검색한다. 검색어는 최대 80자, 분류별 페이지는 최대 50페이지다. 전체 미리보기는 분류당 5개, 분류별 전체 결과는 20개씩 표시한다.
- 입력에 자동 초점을 주고 방향키·Enter·Escape와 Ctrl/Cmd+K를 지원한다. 요청을 취소하고 응답 순서를 확인해 오래된 결과를 다시 표시하지 않는다. 계정·역할·세션이 바뀌면 검색 상태를 초기화한다.
- 방문자는 공개 빌드와 공개 게임 자료를 검색한다. 승인된 실제 멤버는 하이브 자료와 본인의 비공개 빌드를 추가로 검색한다. 다른 사람의 비공개 빌드는 검색하지 않는다. 멤버 검색은 관리자만 제공하며 이름·닉네임만 포함한다.
- 실제 계정은 요청마다 기존 로그인 경로가 검증한 Discord 연결 상태를 사용한다. 로그인 정책과 동일하게 현재 토큰 세대의 서버 가입 확인을 최대 5분 재사용하여 입력마다 별도의 Discord 조회를 중복 호출하지 않는다. DB 역할·계정 연결과 공개 범위는 검색 트랜잭션에서 다시 확인한다. 보관 빌드, 숨김/보관 글·연구 자료, 예약/보관 공지를 제외한다. 연구 자료의 현재 승인 게시와 연결한 고정 빌드 버전의 `PUBLIC` 승인 조건도 확인한다. UID·이메일·OAuth 토큰·이미지 바이트를 조회하거나 반환하지 않는다. 검색 결과는 캐시하지 않는다.
- 개발 계정은 페이지·지도·장비와 표시 중인 게임 정보 미리보기를 검색한다. DB 연결 실패 시 실제 글을 데모로 대체하지 않고 제한 상태를 안내한다.
- 장비 결과는 `/search/items/[id]`에서 설명·확인일·자료 출처와 해당 감염물 지도 링크를 보여준다. 게임 정보 전체 관리 화면의 후속 범위와 구분된다.

## 계정 설정

`/settings`는 로그인한 본인의 프로필 수정, Discord 연결·승인·역할 확인과 로그아웃을 제공한다. 프로필은 기존 검증·저장 경로를 재사용한다. UID는 본인 확인용 비공개 정보로 유지한다.

내 프로필 카드 안에서 이미지를 직접 선택하고 원형 미리보기를 확인한다. 아래의 ‘프로필 수정하기’ 버튼 한 번으로 이미지 변경·삭제와 멤버 식별자, 표시 이름, 닉네임, UID, 소개를 함께 저장한다. 이미지 편집에 별도의 저장 버튼은 없다. 이미지 변경 취소·기본 이미지로 돌아가기와 ‘등록 예시 보기’ 안내 팝업이 있으며, 멤버 식별자와 표시 이름의 입력란 상단은 같은 줄로 맞춘다. 실패 시 프로필 입력과 선택한 이미지가 유지되고, 성공 시 헤더를 갱신한다. 이미지 조회 실패 시 기존 이미지를 유지하는 프로필 정보 저장은 가능하다. 최초 가입의 프로필 등록 방식은 그대로 유지한다.

JPG·PNG·WebP 4MiB 이하만 받는다. 본문 이미지와 같은 공통 업로드 한도를 사용하여 Vercel 요청 본문 제한 안에 multipart 필드 여유를 둔다. 선언된 MIME뿐 아니라 실제 파일 서명·디코더·픽셀 수·프레임 수를 확인하고, 중앙을 기준으로 512×512 WebP로 다시 인코딩한다. PNG·WebP의 투명 배경을 유지하며 등록 이미지의 헤더·설정 미리보기에 기본 아이콘 배경색을 덧씌우지 않는다. JPG는 투명 배경을 지원하지 않는다. EXIF 방향은 적용하되 원본 파일과 EXIF·GPS 등 메타데이터는 보관하지 않는다. GIF·SVG와 움직이는 이미지는 허용하지 않는다. [sharp 입력 제한](https://sharp.pixelplumbing.com/api-constructor/)과 [출력의 메타데이터 기본 제거](https://sharp.pixelplumbing.com/api-output/)를 따른다.

`0007_member_profile_images.sql`은 `member_profile_images`에 사용자별 이미지 한 건을 추가한다. 정규화된 bytea는 512KiB 이내이고 버전은 SHA-256이다. Discord의 `users.image`는 별도로 유지하여 재로그인이 사용자 이미지를 덮어쓰지 않는다. 로그인·헤더·멤버 조회에는 자산 ID와 버전에서 생성한 같은 출처 URL만 전달하며 이미지 바이트를 넣지 않는다. `/api/profile/image/[assetId]`는 로그인과 현재 역할·계정 연결을 다시 확인하고 캐시하지 않는다. 본인(가입 대기 포함)과 관리자는 허용된 이미지를 읽을 수 있고, 다른 승인된 멤버는 승인된 계정의 이미지만 읽는다. 저장·삭제는 현재 서버 로그인 주체의 이미지에 한정한다. 개발 계정은 선택·미리보기만 제공한다.

화면 설정에는 로그인 후 첫 화면, 큰 글자, 애니메이션 줄이기, 홈 안내원 표시가 있다. 직접 지정한 로그인 복귀 주소는 첫 화면 설정보다 우선한다. 큰 글자와 모션 설정은 서버 초기 화면과 저장 직후 화면에 반영한다.

게임 이용에는 기본 지도 시나리오와 최근 파밍 필터 기억을 제공한다. 현재 하이브 시즌은 승인된 진행/정산 시즌을 기준으로 선택하며 없으면 땃쥐 지도를 연다. 명시된 지도 링크가 항상 우선한다. 필터는 기기별·계정별 쿠키에 검증된 공개 시나리오/대상/장소 식별자만 기록하고 공유 코드와 경로는 기록하지 않는다. 기억 설정을 끄면 복원하지 않으며 다음 지도 방문 때 쿠키를 지운다.

새 빌드의 기본 공개 범위는 비공개/하이브/공개 중에서 선택한다. 기존 빌드와 작성 중인 빌드의 공개 범위를 자동 변경하지 않는다.

설정은 `0006_user_preferences.sql`로 추가한 `user_preferences`에 사용자별 JSON object 한 건으로 저장한다. 전체 설정을 엄격하게 검증하고 서버 로그인 주체만 저장 키로 사용한다. 역할·UID·대상 사용자 식별자는 입력에 허용하지 않는다. 저장 전 Discord 연결과 트랜잭션 안의 사용자·계정 연결을 재확인한다. 개발 계정은 실제 DB를 쓰지 않고 계정별 HttpOnly 쿠키에 저장한다. 로드 실패 시 편집 폼을 차단해 기존 설정을 기본값으로 덮어쓰지 않으며 저장 실패 시 작성 값을 유지한다.

## 사이트 알림

헤더 알림을 열면 현재 데이터를 확인한다. 새 공지, 참가한 파티의 실제 변경·취소, 파티 시작 15/30/60분 전 안내, 현재 시즌의 미투표 마감 안내, 본인 글의 댓글을 종류별 설정에 따라 표시한다. 파티 변경은 RSVP로 바뀌는 수정 시각 대신 실제 모집 변경 기록을 기준으로 판단한다. 변경·댓글 기록은 최근 7일, 투표 마감은 24시간 이내를 사용한다.

사이트 안의 알림이며 Discord DM·이메일·브라우저 푸시는 발송하지 않는다. 읽음 이력은 저장하지 않고 고정된 미확인 알림 점을 표시하지 않는다. 알림 설정은 `/settings#notifications`로 연결한다. 승인·계정 연결·본인 참가/글·시즌 상태·숨김/보관 여부를 확인한다. 알림 응답에는 UID·토큰·글 본문을 포함하지 않는다.

## 검증

설정 저장 권한·스키마·계정 격리, 검색 권한·특수문자·공백, 지도 기본값·필터 복원, 새 빌드 기본 공개 범위, 알림 조건과 실제 SQL 조회를 검증한다. DB 검증은 모든 임시 자료를 롤백한다. 브라우저에서 실제 검색 결과 이동, 설정 저장·재방문 적용, 필터 기억 해제/복원, 모바일 레이아웃을 확인했다. 검증 화면은 `outputs/account-search-qa`에 보관하고 실제 계정의 검증용 설정은 원래 기본값으로 복원했다.
